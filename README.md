# seanrleach.co.uk

Personal site and technical blog, built with Jekyll and served by GitHub Pages.

## Run locally

```bash
bundle install
bundle exec jekyll serve
```

## Writing a post

Add a Markdown file to `_posts/` named `YYYY-MM-DD-title.markdown`:

```yaml
---
layout: post
title: "Post title"
description: "One-line summary shown in post lists."
date: 2023-08-15 22:54:12 +0000
categories: one two
---
```
